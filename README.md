# Praktikum React JS - Daftar Tugas Kuliah

Aplikasi praktikum Pemrograman Web dengan React JS (JavaScript) dan Vite.

## Isi

1. Profil Mahasiswa
2. Daftar Mata Kuliah
3. Penghitung Kehadiran (0 sampai 30)
4. Daftar Tugas Kuliah (tambah, selesai, hapus, filter Semua/Aktif/Selesai)

## Instalasi

    npm install

## Menjalankan

    npm run dev

## Build dan Preview

    npm run build
    npm run preview

## Catatan

Folder node_modules tidak disertakan. Jalankan npm install terlebih dahulu.
